# 1η Εργασία Αριθμητικής Ανάλυσης

Ατομική εργασία στο μάθημα Αριθμητικής Ανάλυσης — υλοποίηση αριθμητικών μεθόδων σε 4 ασκήσεις.

## 📁 Περιεχόμενα
├── askisi1/   # Εύρεση ριζών: διχοτόμηση, Newton-Raphson, τέμνουσα
├── askisi2/   # Τροποποιημένες μέθοδοι (Newton-Raphson, διχοτόμηση, τέμνουσα)
├── askisi3/   # LU (PA=LU), Cholesky, Gauss-Seidel
├── askisi4/   # PageRank (πίνακας Google, μέθοδος δυνάμεως)
└── report.pdf # Αναλυτική αναφορά με λύσεις, αποτελέσματα, σχολιασμό


## 📝 Ασκήσεις

1. **Εύρεση ριζών** — f(x) = 14xe^(x−2) − 12e^(x−2) − 7x³ + 20x² − 26x + 12 στο [0,3], με ακρίβεια 6 δεκαδικών, σύγκριση επαναλήψεων και τάξης σύγκλισης.
2. **Τροποποιημένες μέθοδοι** — εφαρμογή σε f(x) = 54x⁶ + 45x⁵ − 102x⁴ − 69x³ + 35x² + 16x − 4 στο [−2,2], ακρίβεια 7 δεκαδικών, σύγκριση ταχύτητας σύγκλισης.
3. **Γραμμικά συστήματα** — PA=LU, Cholesky, Gauss-Seidel (n=10, n=5000), χωρίς built-in συναρτήσεις.
4. **PageRank** — κατασκευή πίνακα Google, μέθοδος δυνάμεως, ανάλυση επίδρασης αλλαγών στο γράφημα και στην πιθανότητα μεταπήδησης q.
